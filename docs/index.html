常见问题

本扩展由个人开发者提供。我们重视您的隐私。本政策说明本扩展如何处理信息。

1. 我们收集哪些数据

我们不收集、不存储、不上传、不出售任何个人数据。

  • 不收集姓名、邮箱、账号密码
  • 不收集浏览历史并发送到第三方服务器
  • 不使用分析/追踪 SDK
  • 不含第三方广告网络；可能展示开发者公告与合作说明（静态 JSON 文本）

2. 本地处理说明

识别与保存都在您的浏览器本地完成。下载文件保存到您设备上的浏览器默认下载目录。

扩展只保存当前页面已经加载、浏览器本身可访问的公开内容，不绕过登录、付费或私密限制。

3. 权限用途

  • activeTab / 页面脚本：识别当前内容页并展示面板
  • storage：仅在本地保存公告缓存与评分偏好
  • 配置站：读取公告、开发合作与商店评分开关
