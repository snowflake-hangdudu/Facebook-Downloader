# Facebook Downloader（Facebook 视频下载助手）

浏览器扩展：在 facebook.com 保存你已经能打开的视频、Reel 和图片。

交互、队列、历史、主题和设置与 X 下载助手相同。区别只在媒体地址的识别：读取 Facebook 页面里的视频/图片地址（`fbcdn.net`），不走 X 的媒体接口。

## 功能

- 首页 / 个人主页 / 小组：有媒体的帖子旁显示「下载」
- 帖子、Reel、Watch：悬浮入口，多图可勾选
- 创作者面板：扫描已加载帖子、解析媒体、批量入队
- 默认隐藏首页赞助内容（设置可关）
- 队列：暂停 / 继续 / 取消 / 重试；中英界面与主题

## 开发

npm test
